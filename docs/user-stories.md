# College ERP User Stories

## 1. Student Registration
As a student, I want to register my personal and academic details
so that I can access the College ERP system.

Acceptance Criteria:
- Valid mandatory details allow account creation.
- Missing mandatory fields display validation errors.
- Duplicate email addresses are rejected.

## 2. Course Registration
As a student, I want to view and register for available courses
so that I can enroll in the required subjects.

Acceptance Criteria:
- Students can view available courses.
- Students can register for eligible courses.
- Successful registration displays confirmation.

## 3. Attendance Tracking
As a faculty member, I want to record student attendance
so that attendance records remain updated.

Acceptance Criteria:
- Faculty can select a class and date.
- Faculty can mark students present or absent.
- Saved attendance can be viewed later.

## 4. Timetable Viewing
As a student, I want to view my class timetable
so that I can plan my academic schedule.

Acceptance Criteria:
- Students can view their class timetable.
- Entries show subject, time, and classroom.
- The timetable is readable on supported devices.

## 5. Fee Payment Status
As a student, I want to view my fee details and payment status
so that I can track outstanding fees.

Acceptance Criteria:
- Students can view the applicable fee amount.
- Paid and pending amounts are displayed.
- Payment status is updated when a payment is recorded.
