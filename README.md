# College ERP System

## Project Overview
The College ERP System helps students and faculty manage academic activities.

## Planned Features
- Student registration
- Course registration
- Attendance tracking
- Timetable viewing
- Fee payment status

## Development Workflow
This project uses Git and GitHub for version control,
branch management, and collaborative development.

## Agile Development Workflow

The College ERP project follows an Agile workflow.

- Student Registration: manage student registration information.
- Course Registration: organize course selection.
- Attendance Tracking: access attendance information.
- Timetable Viewing: review class schedules.
- Fee Payment Status: review fee-related information.

Project changes are tracked using Git and GitHub. Automated tests,
website packaging, and GitHub Pages deployment are handled through
the GitHub Actions CI/CD workflow.
